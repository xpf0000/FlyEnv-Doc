# Guía de licencias de FlyEnv {#guia-de-licencias-de-flyenv}

Puedes usar FlyEnv gratis para tus tareas habituales de desarrollo local. Una licencia de FlyEnv Pro elimina los límites de uso de la versión gratuita y desbloquea las herramientas premium, además de apoyar el desarrollo de FlyEnv.

Ya sea que compres una licencia, contribuyas al proyecto o compartas contenido propio sobre tu experiencia con la comunidad, puedes solicitar la licencia directamente en la app de escritorio de FlyEnv.

## La licencia de un vistazo

| | Licencia personal de FlyEnv |
| --- | --- |
| Precio | $10 USD |
| Pago | Pago único, sin suscripción |
| Validez | De por vida |
| Actualizaciones | Incluye futuras actualizaciones de FlyEnv |
| Dispositivos | Un dispositivo activo por licencia |
| Transferencia a otro dispositivo | Disponible a través de GitHub y Mis Licencias |
| Emisión | Revisión y verificación manuales |

Consulta las opciones de compra y las condiciones vigentes en la [página de licencias](/es/license).

<div id="_2-como-obtener-una-licencia"></div>

## Cómo obtener una licencia {#_2-how-to-get-licensed}

**Compra una licencia, aporta código o comparte tu experiencia.**

Las tres opciones siguen el mismo proceso de solicitud y activación en la app. Cada solicitud se revisa antes de emitir una licencia.

<div id="opcion-a-comprar-una-licencia-personal"></div>

### Opción A. Compra una licencia personal {#option-a-purchase-a-personal-license}

1. Abre la [página de licencias](/es/license).
2. Completa la compra con Paddle o sigue las instrucciones de pago alternativo de esa página.
3. Guarda el ID de pedido o la dirección de correo electrónico que usaste para la compra. Si pagaste por otro medio, guarda el comprobante correspondiente.
4. [Envía una solicitud de licencia en FlyEnv](#_3-request-activation-process).

Para las compras hechas a través de Paddle, Paddle gestiona el pago, los impuestos aplicables, los recibos y las facturas. Si necesitas ayuda con uno de esos pagos, ponte en contacto con Paddle.

::: tip ¿Ya compraste una licencia?
Puedes activar FlyEnv con la compra que ya hiciste. Una vez completado el pago, envía primero los datos de la compra desde **Configuraciones → Licencia**.
:::

<div id="opcion-b-contribuir-al-codigo"></div>

### Opción B. Contribuye a FlyEnv {#option-b-contribute-to-the-codebase}

Ayuda a mejorar el [proyecto de código abierto FlyEnv](https://github.com/xpf0000/FlyEnv) enviando un pull request con una contribución significativa. Puedes aportar funciones nuevas, correcciones de errores, mejoras en la documentación o correcciones de traducción.

Cuando tu contribución esté lista para revisión, incluye el enlace al pull request en tu solicitud de licencia. Durante la revisión manual se evalúa si la contribución cumple los requisitos.

<div id="opcion-c-corre-la-voz-promocion"></div>

### Opción C. Comparte tu experiencia {#option-c-spread-the-word-promotion}

Crea contenido original sobre tu experiencia con FlyEnv. Puedes compartirlo en cualquier idioma en una plataforma adecuada.

| Tipo de contenido | Ejemplos |
| --- | --- |
| Artículos técnicos | Blogs personales, Dev.to, Medium, Hashnode |
| Vídeos y tutoriales | YouTube, Bilibili, TikTok |
| Publicaciones en redes sociales | X, Threads, Facebook, LinkedIn, Instagram |
| Conversaciones entre desarrolladores | Reddit, V2EX y otras comunidades de desarrollo |

Mostrar cómo funciona un proyecto, escribir un tutorial práctico, publicar una comparación o compartir una reseña honesta puede ayudar a otros desarrolladores a descubrir cómo funciona FlyEnv. Tu contenido también puede optar a una licencia si incluye críticas. Encuentra ejemplos de contribuciones de desarrolladores en la [página de la comunidad](/es/community).

#### Requisitos del contenido

- Crea y publica tu propio contenido. Presenta la publicación original para solicitar la licencia.
- Envía la solicitud poco después de publicar. El contenido publicado hace más de tres meses puede dejar de cumplir los requisitos.
- Cada artículo, vídeo o publicación puede optar a una sola licencia. Usa un enlace que no hayas presentado antes para obtener otra licencia.
- Proporciona un enlace accesible para la revisión. Respeta las normas de la plataforma e indica que puedes recibir una licencia a cambio si sus normas lo exigen.

Una vez publicado el contenido, incluye el enlace y tu correo electrónico de contacto en el formulario de solicitud de la app.

<div id="_3-proceso-de-solicitud-y-activacion"></div>

## Solicita y activa tu licencia {#_3-request-activation-process}

Sigue estos pasos después de comprar una licencia o preparar tu contribución. El proceso es el mismo en Windows, macOS y Linux, aunque la interfaz puede variar un poco según la versión.

### Paso 1. Abre la configuración de la licencia

Abre FlyEnv y selecciona **Configuraciones → Licencia** (**Settings → License** en inglés). En la parte superior de la página verás si la licencia está activada en el dispositivo actual. Desplázate hacia abajo hasta la sección de solicitud de licencia.

<p><img src="https://oss.macphpstudy.com/image/flyenv-license-1.webp" alt="Configuración de la licencia de FlyEnv con el estado de activación del dispositivo actual" width="2048" height="1296"></p>

### Paso 2. Introduce los datos de la solicitud

En el campo **Mensaje** (**Message**), escribe un correo electrónico de contacto válido y los datos que correspondan a tu solicitud.

| Tipo de solicitud | Datos que debes incluir |
| --- | --- |
| Compra con Paddle | ID de pedido o correo electrónico asociado a la compra o al recibo |
| Otros medios de pago | Comprobante de pago correspondiente |
| Contribución de código | Enlace al pull request en GitHub |
| Contenido original | Enlace al artículo, vídeo o publicación que compartiste |

Una solicitud por compra podría verse así.

```text
Correo electrónico de contacto: tu@ejemplo.com
ID de pedido de Paddle: TU_ID_DE_PEDIDO
```

Si la solicitud se basa en una contribución a la comunidad, puedes usar este formato.

```text
Correo electrónico de contacto: tu@ejemplo.com
Enlace al contenido: https://example.com/mi-articulo-sobre-flyenv
```

Evita incluir contraseñas, números completos de tarjetas o tokens de acceso a GitHub.

<p><img src="https://oss.macphpstudy.com/image/flyenv-license-2.webp" alt="Formulario de solicitud de licencia con el campo Mensaje y el botón Solicitar Licencia resaltados" width="2048" height="1296"></p>

### Paso 3. Envía la solicitud

Haz clic en **Solicitar Licencia** (**Request License**). FlyEnv revisa las solicitudes manualmente y te avisa por correo electrónico cuando emite la licencia. Asegúrate de conservar el acceso al correo que indicaste.

Basta con enviar la solicitud una vez. Espera a que termine la revisión.

### Paso 4. Activa la licencia

Cuando recibas el correo que confirma la emisión de tu licencia, sigue estos pasos.

1. Vuelve a **Configuraciones → Licencia** en FlyEnv desde el dispositivo que usaste para la solicitud.
2. Desplázate hasta la sección de solicitud y haz clic en **Actualizar Estado** (**Refresh State**).
3. Comprueba el estado de activación en la parte superior de la página **Licencia**. Debería aparecer **Licencia activada** (**License activated**).

<p><img src="https://oss.macphpstudy.com/image/flyenv-license-3.webp" alt="Botón Actualizar Estado en la sección de solicitud de licencia de FlyEnv" width="2048" height="1296"></p>

<p><img src="https://oss.macphpstudy.com/image/flyenv-license-4.webp" alt="Activación de FlyEnv completada con una marca verde y el estado Licencia activada" width="2048" height="1296"></p>

::: info Sobre las capturas de pantalla
Algunas capturas muestran una versión anterior de la app. Las condiciones de licencia y los pasos vigentes son los de esta guía.
:::

### Paso 5. Vincula tu cuenta de GitHub

Cuando tu dispositivo esté activado, busca **Mis Licencias** (**My Licenses**) en la página **Licencia** y usa el botón de inicio de sesión con GitHub para autorizar tu cuenta. Comprueba que tu licencia aparece en **Mis Licencias**.

<p><img src="https://oss.macphpstudy.com/image/flyenv-license-5.webp" alt="Sección Mis Licencias con el botón de inicio de sesión con GitHub resaltado" width="2048" height="1296"></p>

::: tip Vincula tu cuenta de GitHub antes de cambiar de dispositivo
Vincula tu licencia a GitHub ahora, aunque no tengas previsto cambiar de equipo. Así podrás gestionar la licencia por tu cuenta si reinstalas el sistema operativo o pierdes acceso al equipo anterior.
:::

<div id="_4-gestion-de-licencias-y-vinculacion-de-dispositivos"></div>

## Gestiona tus licencias {#_4-license-management-device-binding}

Cada licencia de FlyEnv se asocia al UUID del dispositivo que indica la app. Permite tener un dispositivo activo a la vez y se puede transferir a otro equipo.

Tu cuenta de GitHub vinculada te da acceso a **Mis Licencias**, donde puedes gestionar los dispositivos asociados a tus licencias.

### Transfiere la licencia a otro dispositivo {#transfer-to-another-device}

Si cambias de equipo, puedes reutilizar tu licencia.

1. Instala FlyEnv en el equipo nuevo.
2. Abre **Configuraciones → Licencia → Mis Licencias**.
3. Inicia sesión con la misma cuenta de GitHub que vinculaste a la licencia.
4. Busca la licencia que quieres transferir. Comprueba el UUID vinculado, sobre todo si tienes varias licencias.
5. Abre el menú de acciones de la licencia y selecciona **Desvincular** (**Unbind**) para liberar el dispositivo anterior.
6. Selecciona **Vincular este Dispositivo** (**Bind This Device**) para esa misma licencia.
7. Confirma que el equipo nuevo muestra **Licencia activada**. Si hace falta, pulsa **Actualizar Estado**.

<p><img src="https://oss.macphpstudy.com/image/flyenv-license-6.webp" alt="Sección Mis Licencias con varias licencias y las acciones Desvincular y Vincular este Dispositivo" width="2048" height="1296"></p>

::: warning Un dispositivo activo por licencia
Al transferir una licencia, se desvincula el dispositivo anterior. Si quieres mantener la licencia activa en ambos equipos, necesitas una licencia por equipo.
:::

### Si reinstalas el sistema operativo {#reinstall-your-operating-system}

Al reinstalar Windows, macOS o Linux, el UUID del dispositivo puede cambiar. Si FlyEnv sigue reconociendo tu licencia, puedes continuar usándola. Si FlyEnv deja de reconocerla, sigue los [pasos para transferir la licencia](#transfer-to-another-device) y así desvincular el UUID anterior y vincular el dispositivo actual.

Si nunca vinculaste la licencia a GitHub y ya no tienes acceso a la instalación anterior, [contacta con el equipo de soporte](#get-help) para que verifique tu licencia y te ayude.

### Usa FlyEnv en varios equipos {#use-flyenv-on-multiple-computers}

Si quieres usar FlyEnv en varios dispositivos al mismo tiempo, puedes comprar más licencias o solicitarlas mediante una contribución que cumpla los requisitos. Por ejemplo, puedes tener una licencia para tu equipo de trabajo y otra para tu equipo personal.

### Gestiona varias licencias

**Puedes gestionar varias licencias con una sola cuenta de GitHub.**

Puedes asociar varias licencias independientes de FlyEnv a la misma cuenta de GitHub. Si vinculas o transfieres una licencia, las demás siguen funcionando de forma independiente. Selecciona la licencia correcta antes de desvincular un dispositivo.

## Funciones gratuitas y con licencia {#_1-evaluation-version-limitations}

Las funciones principales de desarrollo local están disponibles gratis, incluida la gestión de entornos de ejecución y bases de datos, HTTPS y Startup Groups. Algunas funciones tienen los siguientes límites.

| Función | Gratis | Pro |
| --- | --- | --- |
| Sitios locales | Hasta 3 | Sin límite de sitios |
| Proyectos personalizados | Hasta 3 por entorno de ejecución | Sin límite de proyectos |
| Cloudflare Tunnel | 1 túnel | Varios túneles |
| Asistente de IA | Prueba de 3 días | Acceso completo |
| Herramienta de capturas de pantalla | Prueba de 3 días | Acceso completo |
| Optimizador de imágenes | Prueba de 3 días | Acceso completo |
| Plugin Market | Requiere una licencia activa para instalar y actualizar complementos | Permite instalar y actualizar complementos |

Estos límites se aplican a las funciones de FlyEnv. Los programas y servicios de terceros pueden tener sus propias condiciones, requisitos de plataforma o costes.

Para conocer los módulos opcionales, consulta la [guía del catálogo de complementos](/es/features/plugin-market). Para saber más sobre el servidor MCP integrado, consulta la [guía del espacio de trabajo con IA y MCP de FlyEnv](/es/guide/ai-coding-workspace-mcp).

## Preguntas frecuentes {#frequently-asked-questions}

### Ya pagué una licencia. ¿Por qué FlyEnv sigue sin activarse?

La compra y la activación son pasos distintos. Comprueba que el pago se completó y [envía tu solicitud de licencia](#_3-request-activation-process) en FlyEnv. Cuando recibas el correo que confirma la emisión, haz clic en **Actualizar Estado** en la página **Licencia**.

### Mi solicitud de licencia sigue pendiente. ¿Qué hago?

Las solicitudes se verifican manualmente. Revisa el correo electrónico de contacto que indicaste, incluida la carpeta de correo no deseado. Si crees que los datos de tu solicitud son incorrectos o todavía no has recibido respuesta, [contacta con el equipo de soporte](#get-help) e incluye los datos de tu solicitud.

### El pago falló. ¿Todavía puedo obtener una licencia?

Solo un pago completado sirve como comprobante de compra. Comprueba el estado del pago antes de enviar una nueva solicitud. Si el medio de pago no está disponible en tu región, consulta las alternativas en la [página de licencias](/es/license).

### ¿Necesito otra licencia después de reinstalar el sistema?

Puedes seguir usando tu licencia. Si cambió el UUID del dispositivo, usa la cuenta de GitHub vinculada para transferir la licencia al dispositivo actual.

### ¿Qué hago si pierdo el equipo anterior o si ya no funciona?

Si vinculaste la licencia a GitHub, puedes gestionar la vinculación desde el equipo nuevo sin tener acceso al anterior. Si tenías la licencia sin vincular, contacta con el equipo de soporte para recuperar tu licencia.

### ¿Puedo usar la misma licencia en dos equipos?

Si quieres tener dos equipos con licencia activa al mismo tiempo, cada uno necesita su propia licencia. Puedes gestionar varias licencias desde la misma cuenta de GitHub.

### ¿Puedo usar un artículo o una compra que ya presenté?

Solo puedes usar una contribución o un enlace una vez para solicitar una licencia. Con cada compra puedes solicitar la cantidad de licencias adquiridas. Si quieres transferir una licencia que ya tienes, usa **Mis Licencias**.

### ¿Caduca mi licencia? ¿Incluye futuras actualizaciones?

La licencia personal vigente es de por vida, sin pagos periódicos. La política de licencias actual incluye las futuras actualizaciones de FlyEnv.

### ¿Hay licencias para equipos de trabajo o centros educativos?

Las condiciones para equipos de trabajo y centros educativos se pueden consultar caso por caso. Usa los datos de contacto de la [página de licencias](/es/license) e indica tu organización, el uso previsto y el número de dispositivos.

## Obtén ayuda {#get-help}

Si estos pasos no resuelven tu problema, usa los datos de contacto de la [página de licencias](/es/license). Si se trata de un problema técnico general, consulta la [página de incidencias en GitHub](https://github.com/xpf0000/FlyEnv/issues).

Para pedir ayuda en privado con tu licencia, proporciona el correo electrónico que usaste en la solicitud, el ID de pedido o el enlace a tu contribución, y una breve descripción del problema. Incluye tu versión de FlyEnv y el UUID del dispositivo actual si son pertinentes.

Evita publicar recibos, direcciones de correo personales, números de licencia o identificadores de dispositivos en incidencias o conversaciones públicas.
