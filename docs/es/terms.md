## Producto

FlyEnv es una aplicación de escritorio multiplataforma para gestionar entornos de desarrollo local en macOS, Windows y Linux. Ayuda a los desarrolladores a instalar, configurar y cambiar entre runtimes, bases de datos, servidores web, herramientas de IA y otros servicios de desarrollo local.
