# License Policy Copy Update

## Scope

Update only the Chinese and English FlyEnv licensing guides:

- `docs/zh/guide/about-license.md`
- `docs/guide/about-license.md`

No changes will be made to the purchase page, Terms of Service, Refund Policy, or application UI.

## Required Content

### License Acquisition

The three acquisition paths (purchase, code contribution, and promotion) all require manual review before FlyEnv issues a license. The purchase path must no longer imply automatic license issuance after payment.

### Current Policy

State that licenses purchased under the current policy are permanently valid. Also state that FlyEnv may change the policy to annual subscriptions in the future; do not imply that an existing permanent purchase will expire.

### Request and Activation

Add the first step before proof submission:

1. Open FlyEnv Settings, select License, then scroll to the bottom to find the license request area.
2. Enter the applicable proof in the Message field.
3. Submit the request.
4. Wait for manual review and license issuance, normally within 24 hours.

## Language Consistency

The Chinese and English pages will convey the same policy. Each version will use its existing terminology and Markdown style.

## Verification

Run the production documentation build after editing to verify both pages render successfully.
