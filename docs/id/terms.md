# Ketentuan Layanan

Terakhir diperbarui: 16 Mei 2026

Ketentuan Layanan ("Ketentuan") ini mengatur akses dan penggunaan Anda atas FlyEnv, termasuk situs web, dokumentasi, aplikasi desktop, lisensi, pembaruan, dan layanan terkait FlyEnv.

FlyEnv dioperasikan oleh Pengfei Xu dengan merek FlyEnv. Untuk pertanyaan tentang Ketentuan ini, hubungi [alexpengfeixu@gmail.com](mailto:alexpengfeixu@gmail.com).

## Produk

FlyEnv adalah aplikasi desktop lintas platform untuk mengelola lingkungan pengembangan lokal di macOS, Windows, dan Linux. Aplikasi ini membantu pengembang memasang, mengonfigurasi, dan beralih antara runtime, database, server web, alat AI, serta layanan pengembangan lokal lainnya.

FlyEnv dapat menawarkan edisi komunitas gratis dan lisensi atau langganan berbayar untuk fitur premium, batas yang lebih luas, atau dukungan.

## Kelayakan

Dengan menggunakan FlyEnv, Anda menyatakan bahwa Anda dapat menyetujui Ketentuan ini secara sah dan bahwa penggunaan FlyEnv oleh Anda mematuhi hukum dan peraturan yang berlaku.
