## 周期与导出

1. 记录每批发布日期、语言、页面范围、GA4 设置生效日期与事故。按相同 28 天周期导出，另看 3/6/16 个月和同期趋势。低流量组延长观察。
2. GA4 探索用行维度分别导出「网页路径 × 事件名称」「着陆页（含查询字符串） × 事件名称」全渠道与 `Session source / medium = google / organic` 两份，以及「会话来源/媒介 × 事件名称」。校对同区间、时区、过滤器、事件合计与数据阈值，导出中禁止留敏感查询参数。用 GA4 路径过滤或安全本地脚本去 query 和 `.html` 做内容分组，语言保留为单独维度。
3. GSC Search results 选择 Web 与相同周期，导出 Queries、Pages、Countries、Devices、Search appearance 和 filters。跟踪 Clicks、Impressions、CTR 与主要查询，标记日期和导出限额。
4. 衡量老版事件密度 = 事件数 / `session_start` 事件数 × 100。会话关键事件率 = 有事件的独立会话 / 总会话数，使用 GA4 内建口径。有意图不代表实际安装或购买，下载事件不求和。GSC 点击不作 GA4 分母。
5. 分开看下载导航、实际包点击、自动文件事件、许可证导航和购买按钮点击。新增事件覆盖及管理台生效后建立新基线，注明与任务书的边界。若 CLIProxyAPI CTR 提高而获客动作无可辨识提升，维持单页实验规模。Compare、Guide、Solutions 扩量后结合搜索词和地区评估事件密度。
