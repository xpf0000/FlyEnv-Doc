# FlyEnv SEO Content Expansion — Phase 1

## Objective

Increase FlyEnv's non-brand organic search coverage by converting existing product capabilities and competitive positioning into dedicated pages that Google and users can understand independently.

The goal is **not** to maximize page count.

The goal is to create pages that:

- answer a real search intent
- accurately reflect FlyEnv's actual product
- connect existing Guides, Solutions, Demos, and Download flows
- can earn impressions and rankings independently
- remain maintainable as FlyEnv evolves

## Scope

### A. Features

Create a dedicated Feature page for every stable FlyEnv module/capability that has enough substance to answer a distinct search intent.

Examples of likely categories:

- Web Servers
- Languages / Runtimes
- Databases
- Cache / MQ
- Storage / Infrastructure
- Database Management Tools
- Development Workflow / Productivity
- AI / MCP
- Other stable product modules discovered from the repository

The repository is the authority for the final inventory.

### B. Compare

Create dedicated pages for the approved competitors:

- XAMPP
- Laragon
- MAMP
- Laravel Herd
- Docker Desktop
- ServBay

Potential additional competitors may be proposed but must not be created without approval.

Each page should map to a distinct search intent, for example:

- XAMPP alternative
- FlyEnv vs XAMPP
- Laragon alternative
- FlyEnv vs Laragon

## Out of scope

Do not create new:

- Solutions pages
- generic blog content
- bulk "how to" articles
- location pages
- language/localization variants
- programmatic keyword permutations

Existing Solutions pages should be reused through internal links.

## Success criteria

Phase 1 is complete when:

1. all approved stable FlyEnv modules have reviewed Feature pages where appropriate;
2. all approved competitor pages exist and are fact-checked;
3. Features has a usable index/landing page;
4. Compare pages are discoverable through Guide sidebar navigation;
5. new pages build cleanly;
6. no new broken internal links are introduced;
7. sitemap/canonical behavior is correct;
8. page inventories and research state are current.

## Post-phase measurement

After publication, review Google Search Console for 4–8 weeks.

Track:

- non-brand queries
- impressions
- average position
- pages entering Top 50 / Top 20 / Top 10
- CTR
- cannibalization
- unexpected query intent

Do not judge the project primarily by an SEO-audit score.
