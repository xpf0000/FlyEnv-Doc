## Content

## SEO

- [ ] Exactly one H1.
- [ ] Clean canonical URL.
- [ ] Useful H2/H3 structure.
- [ ] No empty anchors introduced.
- [ ] Relevant internal links.
- [ ] Page appears in intended index/sidebar.
- [ ] Sitemap includes canonical page.

## Build / QA
- [ ] Production build passes.
- [ ] No new 4xx internal links.
- [ ] No obvious duplicate/cannibalized page.
- [ ] Existing mobile layout remains usable.
- [ ] Inventory status updated.
- [ ] Spec/research artifacts saved.
