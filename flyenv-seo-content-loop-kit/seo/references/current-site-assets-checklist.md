# Existing FlyEnv Assets to Reuse

Before drafting a new Feature or Compare page, search the repository for:
- current homepage copy
- current Guide pages
- current Solutions pages
- current Demos pages
- README
- release notes
- module screenshots
- demo videos
- product UI screenshots
- existing diagrams
- FAQ content
- license/download/getting-started pages

The goal is to connect existing assets, not duplicate them.

Example conceptual pattern:

```text
/features/php
    -> PHP guide
    -> Laravel solution
    -> WordPress solution
    -> Nginx/Apache/Caddy features
    -> MySQL/PostgreSQL/Redis features
    -> relevant demo
```

The exact links must be derived from the current repository.
