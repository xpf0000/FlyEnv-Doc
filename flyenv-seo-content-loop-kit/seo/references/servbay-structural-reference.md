# ServBay Structural Reference Notes

This file is a **structural reference**, not a content source.

Use ServBay only to study patterns that may explain broad keyword coverage.

## Useful patterns to study

### Feature decomposition
Study which capabilities receive dedicated pages and which search intent each page targets.

### Comparison pages
Study how comparison pages:
- frame products
- choose dimensions
- use quick-answer sections
- use tables
- acknowledge where the competitor fits
- add FAQs
- link to deeper product pages

Do not import their conclusions.

### Internal topic graph
Observe how pages connect runtime -> framework/project, web server -> HTTPS/local sites, database -> tool, competitor -> feature, and feature -> docs.

### Content depth
Long content is not a goal by itself. Replicate only useful coverage, not word count.

## Explicit prohibition
Never copy or closely paraphrase ServBay copy.
Never use ServBay as factual evidence for FlyEnv.
Never use ServBay as the sole factual source for a competitor.
