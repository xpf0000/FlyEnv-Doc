# Prompt 05 — Review Existing Phase 1 Pages

Do not create new pages in this iteration.
Review all completed Phase 1 Feature and Compare pages.

Check for:
- duplicate title/description
- content duplication
- keyword cannibalization
- inconsistent terminology
- stale claims
- weak internal linking
- broken links
- missing canonical
- missing sitemap entry
- pages with no inbound links
- generic AI filler
- sections that do not answer real user intent

If Google Search Console or Semrush exports are available locally, use them only as measurement inputs.
Prioritize improvements to pages that already show:
- impressions
- positions 8–50
- weak CTR
- promising non-brand queries

Produce a prioritized improvement report under `seo/reports/`.
