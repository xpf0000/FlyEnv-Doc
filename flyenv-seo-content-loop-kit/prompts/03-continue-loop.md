# Prompt 03 — Continue SEO Content Loop

Continue the approved Phase 1 SEO content loop.
Read the current inventories and state.
Process the next highest-priority approved items.
Default limit: **maximum 3 new pages in this iteration**.

Priority order unless inventory indicates otherwise:
1. unfinished high-value Features
2. approved Compare pages
3. improvements required by validation

For every page:
- research first
- create/update its spec
- verify claims
- implement
- add natural internal links
- build
- run SEO/link validation
- fix failures
- update inventory/state

Do not expand into Solutions, generic How-to content, localization, or unapproved competitors.
If a competitor page cannot be fact-checked using current official information, stop that page and record the research gap rather than guessing.
