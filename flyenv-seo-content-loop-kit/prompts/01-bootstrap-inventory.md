Read, in order:
1. `AGENTS.md`
2. `docs/seo-content-project.md`

4. `docs/site-information-architecture.md`

Then inspect the current FlyEnv website repository, product source/module definitions, README, Guides, Solutions, Demos, and relevant release notes.

## Task
Build an authoritative inventory of stable, user-facing FlyEnv modules that deserve dedicated Feature pages.
Do **not** create or modify website pages yet.

Update `seo/inventory/features.yaml` with:
- real product categories
- feature/module name
- proposed slug
- evidence locations
- existing related Guide/Solution/Demo pages
- proposed priority
- current status
- any ambiguity

Also review `seo/inventory/competitors.yaml` and flag any issue with the approved competitor set.

## Required output
1. updated Feature inventory
2. missing Feature-page list
3. proposed Feature category structure
4. duplicate/cannibalization risks
5. existing pages that may already satisfy a Feature intent
6. implementation order for the first 10 Feature pages
7. questions requiring human approval

Do not write content pages in this iteration.
Do not invent modules that are not verifiable in the current repository.
