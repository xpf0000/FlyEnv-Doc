# Prompt 02 — First Feature Implementation Batch

Use the approved Feature inventory.
Read the SEO content skill and project rules first.
Select the highest-priority Feature items with `status: todo`.
Create **no more than 3 new Feature pages** in this iteration.

For each selected Feature:
1. research current FlyEnv implementation and documentation;
2. create `seo/specs/features/<id>.md` using the Feature spec template;
3. identify relevant existing Guides, Solutions, Demos, and related Features;
4. implement the page;
5. add/update the `/features` index/navigation only as required;
6. ensure metadata and clean canonical URL are correct;
7. run production build;
8. run available SEO/broken-link checks;
9. fix issues;
10. update the inventory status and evidence.

## Content requirements
- no generic filler
- no unsupported claims
- no arbitrary minimum word count
- no near-duplicate template copy
- use real product screenshots/assets where practical
- do not create new Solutions or How-to pages

At the end, report:
- pages created
- files modified
- validation run
- unresolved risks
- next recommended items
